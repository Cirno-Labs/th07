# orig/

Put your own copy of the game here. Nothing in this directory except this
file and the `.sha1` list is tracked.

The target is 東方妖々夢 1.00b (2003-10-24), the last update: the files
from the retail CD, updated by the official `youmu_update100b.lzh` patch
from <https://www16.big.or.jp/~zun/html/th07_update.html>. The patch
updates `th07.exe`, `custom.exe` and `th07.dat`.

```
orig/th07_100b/            the installed game
orig/th07_100b/th07.exe    updated to 1.00b
```

```sh
sha1sum -c th07_100b.sha1
```

The checksums are not recorded yet: add them to `th07_100b.sha1` from a
verified copy. `th07.dat` must be the original, patched to 1.00b; English
patches replace it.
